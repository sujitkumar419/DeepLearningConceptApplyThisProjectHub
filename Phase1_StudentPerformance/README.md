# 📊 Phase 1: Student Performance Prediction + Career Recommendation

## 📌 Overview
This project is the first phase of the **CareerFitPipeline**.  
It focuses on analyzing student performance data, predicting outcomes (Pass/Fail), and providing career recommendations based on academic results.  
The goal is to apply core ML concepts and build a structured pipeline with clean code and visualization.
